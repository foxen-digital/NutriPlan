## Introduction
The `OpenAiClient.php` file contains the `OpenAiClient` class, which serves as an interface for interacting with the OpenAI API, specifically for requesting chat completions. This class abstracts the complexities of API calls to the OpenAI service, allowing developers to focus on application logic without needing to manage HTTP requests and responses directly. The main responsibilities of this client include setting the desired AI model and making requests for chat completions based on a series of messages.

## Constructor
```php
public function __construct(private readonly string $apiKey, private string $model = 'gpt-4o-mini')
```
### Purpose
The constructor initializes an instance of the `OpenAiClient` class with the required API key for authentication and an optional model parameter, defaulting to `gpt-4o-mini`.

### Parameters
- `string $apiKey`: The API key to authenticate requests to the OpenAI API. This value is mandatory.
- `string $model`: The AI model to be used for generating responses. This parameter is optional and defaults to 'gpt-4o-mini'.

### Functionality
The constructor ensures that an instance of `OpenAiClient` can be created by providing an API key. It also allows the flexibility of setting different models for AI requests as needed.

## Method: setModel
```php
public function setModel(string $model): self
```
### Purpose
The `setModel` method allows users to specify which AI model to use for subsequent chat completion requests.

### Parameters
- `string $model`: The name of the AI model that should be used for generating responses.

### Return Value
- `self`: Returns the current instance of `OpenAiClient` for method chaining.

### Functionality
This method updates the model used for generating outputs. It is useful for switching between various AI models (e.g., `gpt-4`, `gpt-3.5`, etc.) as per the application's requirements.

## Method: getChatCompletion
```php
public function getChatCompletion(array $messages, array $options = []): Response
```
### Purpose
The `getChatCompletion` method is responsible for making an HTTP POST request to the OpenAI API for generating chat completions based on an array of message prompts.

### Parameters
- `array $messages`: An array of messages that form the chat history. Each message should include a role (e.g., `"user"` or `"assistant"`) and content.
- `array $options`: Optional additional settings for the request, such as temperature settings or max tokens. This parameter defaults to an empty array.

### Return Value
- `Response`: Returns an instance of `Illuminate\Http\Client\Response`, which contains the HTTP response from the OpenAI API.

### Functionality
This method composes the payload required for the API call, including the model and messages. It sends a POST request to the endpoint `https://api.openai.com/v1/chat/completions` with the appropriate authentication token. The method returns the response from the OpenAI API, allowing for further handling of the response data by the calling code. 

Overall, this method encapsulates the complexity of HTTP requests and offers a simple interface for fetching responses generated by OpenAI's models.
