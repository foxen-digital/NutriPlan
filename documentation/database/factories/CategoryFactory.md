## Introduction
The `CategoryFactory` class is part of the `Database\Factories` namespace and serves a crucial role in testing and seeding database records for the `Category` model within the NutriPlan PHP application. This factory leverages Laravel's built-in factory methods to generate dummy data that can be used during testing. By defining how to create instances of the `Category` model, the `CategoryFactory` class facilitates the development of automated tests and helps populate the database with test data in a structured way.

## Class Definition
```php
class CategoryFactory extends Factory
```
The `CategoryFactory` class extends the `Factory` class provided by Laravel, which enables it to create new instances of the associated `Category` model with predefined attributes.

### Properties
- **model**: 
  - Type: `class-string<Category>`
  - Value: `Category::class`
  - Description: This property specifies the model that the factory corresponds to, in this case, the `Category` model.

## Methods

### definition
```php
public function definition(): array
```
#### Purpose
This method defines the default attributes for the `Category` model instances generated by the factory.

#### Parameters
- None

#### Return Values
- Type: `array<string, mixed>`
- Description: An associative array representing the default attributes for a `Category` instance.

#### Functionality
The `definition` method employs the `fake` helper to generate realistic dummy data for the properties of the `Category` model:
- `'name'`: A unique string consisting of two words.
- `'description'`: An optional sentence providing a description of the category.
- `'is_active'`: A boolean value set to `true`, indicating that the category is active by default.

### Example Output
```php
[
    'name' => 'Healthy Snacks',
    'description' => 'A collection of snacks that are good for health.',
    'is_active' => true,
]
```

### inactive
```php
public function inactive(): static
```
#### Purpose
This method indicates that the category being generated should be marked as inactive.

#### Parameters
- None

#### Return Values
- Type: `static`
- Description: Returns the factory instance itself, allowing for method chaining.

#### Functionality
The `inactive` method uses the `state` method to modify the default state of the `Category` instance being built:
- It sets the `'is_active'` attribute to `false`, indicating that the category should be considered inactive.

### Example Usage
```php
$inactiveCategory = CategoryFactory::new()->inactive()->create();
```

This would produce a `Category` instance with `is_active` set to `false`.

The `CategoryFactory` is a vital component within the NutriPlan project's testing and data seeding functionalities, providing developers with the tools necessary to work with `Category` model instances seamlessly.
